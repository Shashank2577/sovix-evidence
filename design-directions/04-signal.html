Conventions

fired: review_coverage < 50 · ruleset rccef86aa

Thresholds are configurable policy conventions, not universal performance standards.

Only GitHub review records count. Approval given in a plain comment, over chat, or in person is invisible — verify against the listed examples before treating a low number as a finding.

83 of 90 merged pull requests carry no review record. If this team approves changes verbally or in chat, that practice is invisible here.
